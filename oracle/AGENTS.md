# Oracle engineering

For Oracle defects, trace and fix the shared mechanism, audit related supported
capabilities, and add cross-subject conversation regressions. Treat supplied
production questions as acceptance examples, not the complete specification.
Avoid exact-phrase exceptions unless a semantic requirement justifies them.
Document unsupported capabilities and live verification separately.

Terminal delivery must be reviewed across direct /agent, interactive chat,
lease-owned durable persistence, authenticated polling and browser recovery.
Use the shared result contract after strict evidence-scope validation. Preserve
validated evidence/artifacts when presentation fails; never repeat provider calls
as a rendering repair. Worker completion does not verify browser delivery.
Audit governed grain, measures and filters before adding analytical operations;
period aggregates do not establish complete order distributions or scenarios.
